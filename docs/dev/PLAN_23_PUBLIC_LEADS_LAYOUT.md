# 开发计划：v0.23 公海线索布局重构

> **背景**：用户实测后认为当前页面组织方式不理想，要求调整顶部栏布局 + 双 Tab 搜索状态独立。

---

## 一、当前布局（问题）

```
┌──────────────────────────────────┐
│ LeadsTopBar (排序/筛选)          │  ← 占一整行
├──────────────────────────────────┤
│ AppSearchBar (搜索)              │
├──────────────────────────────────┤
│ TabBar (我的线索 / 公海线索)     │  ← 独立一行，与顶部栏分离
├──────────────────────────────────┤
│ 筛选标签 / 列表                  │
└──────────────────────────────────┘
```

## 二、目标布局

```
┌──────────────────────────────────┐
│ 我的线索 │ 公海线索    [排序][筛选] │  ← 顶部栏：左侧 Tab + 右侧操作按钮
├──────────────────────────────────┤
│ AppSearchBar                     │  ← 搜索栏（独立状态）
├──────────────────────────────────┤
│ 筛选标签 / 列表                  │
└──────────────────────────────────┘
```

关键变化：
- 顶部栏从「整行排序/筛选」改为「左侧 Tab 切换 + 右侧排序/筛选」
- 删除独立一行的 TabBar
- 搜索状态独立：切换 Tab 时不丢失已输入的搜索词

---

## 三、改动方案

### 3.1 顶部栏重构（`leads_top_bar.dart` → 改造）

当前 `LeadsTopBar` 是一个整行控件（左侧标题+排序，右侧筛选按钮）。需要改造为：

```
┌──────────────────────────────────────┐
│ ┌──────┬──────┐         [排序] [筛选] │
│ │ 我的  │ 公海 │                     │  ← 左侧用 Expanded + GestureDetector
│ └──────┴──────┘                     │
└──────────────────────────────────────┘
```

改造方案：
- `LeadsTopBar` 新增参数：`activeTab`（0/1）、`showPublicTab`（bool）、`onTabChanged`
- 左侧：两个 Tab 标签（选中态蓝色下划线 + 加粗，未选中灰色）
- 右侧：原有的排序/筛选按钮（始终可见，但筛选仅对我的线索生效）
- 取消 `_buildTabBar()` 独立方法，功能合并到 `LeadsTopBar` 中

### 3.2 搜索状态独立

当前问题：
- 单 `_searchCtrl` 控制器，切换 Tab 时搜索词丢失
- `_publicKeyword` 与文本框不同步

解决方案：
- 双控制器：`_mineSearchCtrl` + `_publicSearchCtrl`
- build 时根据 `_activeTab` 选择显示哪个控制器
- 切换 Tab 时调用 `_searchCtrl.clear()` 改为切换控制器引用
- 实际做法：将当前 Tab 的搜索控制器赋值给 `_searchCtrl` 引用（或直接使用两个 `TextEditingController`）

具体实现：
- 删除 `_searchCtrl`，改为 `_mineSearchCtrl` + `_publicSearchCtrl`
- 在 `_buildTabItem.onTap` 切换 Tab 时，不需要额外处理搜索状态（因为两个控制器各自独立）
- AppSearchBar 的 `controller` 根据 `_activeTab` 传入不同控制器
- 公海搜索的触发逻辑复用 `_loadPublicLeads`

### 3.3 排序/筛选对公海 Tab 的支持

当前排序/筛选只对我的线索生效。重构后：
- 在我的线索 Tab：排序/筛选行为不变（操作 `leadListProvider`）
- 在公海线索 Tab：排序按钮可切换排序字段（`-updatedAt` 等），筛选按钮暂不显示或显示简化筛选（公海没有状态筛选）
