# 公海线索卡片优化方案（PUBLIC_LEAD_CARD）

> 日期：2026-07-26
> 范围：`lib/pages/leads/widgets/public_lead_card.dart` + `lib/pages/leads/leads_list_page.dart`（仅公海卡片调用处）
> 原则：**仅 UI / 布局调整 + 关闭越权入口，不改动领取业务逻辑**

---

## 一、现状（问题定位）

### 1. 卡片内容过高
当前结构（自上而下）：

```
┌─────────────────────────────────────┐
│ 姓名（16 w500）        [待跟进 标签] │  ← 行1
│ 📞 138 0000 0000                  │  ← 行2（电话）
│ [商铺] 阳光花园项目                │  ← 行3（分类 + 项目）
│ 🕐 最后更新: 2小时前              │  ← 行4（时间）
│ ──────────────────────────────── │  ← 分割线
│                        [ + 领取该线索 ]│  ← 底部按钮条
└─────────────────────────────────────┘
```

- 4 行信息 + 分割线 + 底部按钮条，**整卡约 180px+**。
- 公海线索信息量其实比「我的线索」少（无归属人、无跟进计划徽章），却占了相近高度，显得空、显得高。
- 行2/行4 都是单行图标+文字，视觉上可合并压缩。

### 2. 越权入口（点卡片进详情）
- `public_lead_card.dart:37` 用 `GestureDetector(onTap: onTap)` 把整张卡包住。
- `leads_list_page.dart:529` 传 `onTap: () => Navigator.push(LeadDetailPage(leadId: lead.id))`。
- 即：**员工点公海卡片任意位置都会进线索详情**，但员工本无权限查看公海线索详情（只有领取到自己名下才行）。这是越权 + 点了白点（服务端大概率会 403）。

---

## 二、优化方案

### 改动 A：重新排版，压低卡片高度

**新结构（2 行信息 + 头行内联领取按钮，去掉底部按钮条和分割线）：**

```
┌─────────────────────────────────────────────┐
│ 姓名（16 w500）            [ + 领取该线索 ]   │  ← 头行：姓名 + 领取按钮内联
│ 📞 138 0000 0000   ·   🕐 2小时前            │  ← 元信息行：电话 · 更新时间（单行合并）
│ [商铺] 阳光花园项目                         │  ← 分类标签 + 项目名（单行）
└─────────────────────────────────────────────┘
```

**具体做法：**
1. **去掉底部「分割线 + 领取按钮条」**（省约 52px）。
2. **领取按钮上移到头行右上角**，与姓名同一行：`Row([Expanded(姓名+状态标签)], [领取按钮])`，按钮高度由 36 缩到 32、紧凑胶囊样式不变。
3. **电话 + 更新时间合并为一行**：`📞 138xxxx  ·  🕐 2小时前`（中点分隔），行2/行4 合并。
4. 分类标签 + 项目名保留单行（已有，不动）。
5. 内边距从 `16` 略收到 `14`，行间距收紧。

**高度对比（估算）：** ~183px → ~120px，**缩短约 1/3**，且去掉了底部留白感。

### 改动 B：关闭越权入口（卡片不可点进详情）

1. `public_lead_card.dart`：**移除 `GestureDetector` 整卡包裹**（改成直接 `Container`），**删除 `onTap` 构造参数**。
2. `leads_list_page.dart:529-535`：**删除 `onTap: () => Navigator.push(LeadDetailPage(...))`**，只保留 `onClaim`。
3. 卡片变为纯展示 + 唯一可点元素「领取」按钮（保留 `claiming` 加载态、错误回退逻辑完全不动）。
4. **可选 UX 提示**：在元信息行末尾加一个极小的灰字 `领取后可查看`（或姓名前加 🔒 图标），解释为何不可点。默认不加（避免再加高），如你要我可加上。

> 越权入口关闭后，员工若想看公海线索详情，只能先「领取」→ 进入「我的线索」→ 再点详情，符合权限模型。
