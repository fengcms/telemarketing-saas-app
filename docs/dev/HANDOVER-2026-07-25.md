## 二、重点功能详情

### 1. 首页日程接口合并（v0.27，PLAN_25）

**痛点**：首页原并行发 **4 个**请求（`stats/mine` 四宫格 + `schedules` 待办预览 + `schedules/stats/mine` 统计 + 时间范围查询到期数）。

**方案**：后端新增聚合端点 `GET /api/tenant/schedules/home-summary`，无参、鉴权一致，一次返回：
```json
{
  "todayPending": 42,     // 严格今日窗口（排除历史逾期）
  "dueSoonCount": 2,       // 未来 30 分钟到期提醒
  "pendingTotal": 56,       // 全量待办（预留查看全部）
  "schedules": [ /* 前 5 条 pending 预览，结构与 Schedule.fromJson 同构，含 lead 快照 */ ]
}
```

**改动（6 文件）**：
- `api_constants.dart`：加 `homeSummary` 常量（保留 `schedulesStatsMine`，供 Tab/个人中心复用）
- `home_service.dart`：删 `fetchPendingSchedules`/`fetchMyScheduleStats`/`fetchDueSoonCount` + 死代码 `_toInt`；新增 `fetchHomeSummary()`；保留 `fetchMyStats` 与静态 `getServerTime`
- `models/home_summary.dart`（新建）：`HomeSummary.fromJson`，`schedules` 复用 `Schedule.fromJson`
- `home_provider.dart`：`HomePageState` 增 `todayPending`、删 `scheduleTotal`；`loadData`/`_silentRefresh` 改 2 并发
- `home_stats_section.dart`：四宫格「今日到期」改读 `todayPending`
- `home_schedule_section.dart`：待办 Badge 改读 `todayPending`

**首屏请求 4 → 2**（仅 `stats/mine` + `home-summary`）。

### 2. 通话记录列表优化（v0.28，PLAN_26）

**需求**：① 列表加 5 分钟缓存，避免每次进入都请求；② 仅 `tenant_manager`/`tenant_admin`（TM/TA）角色在卡片拨打时间行后追加「拨打人：xx」，姓名由 `userId` → `OptionsCacheService.getUserName` 映射。

**改动（3 文件）**：
- `call_service.dart`：`fetchMyCalls` 加 `force` 参数；服务层加首屏缓存（`_cache`/`_cacheKey`/`_cacheTime` + `peekCache`），仅 `page==1 && !force` 写/读，翻页与强制刷新不缓存，TTL=300s
- `call_records_page.dart`：`initState` 读 `authProvider.user.role` 定 `_showCaller`（仅真实枚举值）；`_loadInitial({force})` 先 `peekCache` 命中直接套用（无骨架无请求）并 return，否则走网络透传 `force`；套用后统一 `_resolveCallers()` 用 `getUserName` 解析；`_onRefresh` 透传 `force:true`
- `call_record_row.dart`：加 `callerName` 参数；时间行改 `Text.rich`，后追加 `· 拨打人：<姓名>`

**两个确认点（用户拍板）**：角色判定只用 `tenant_manager`/`tenant_admin` 真实值（TM/TA 缩写不写进代码）；下拉刷新绕过缓存；拨打人纯文字、无彩色圆点。

### 3. 线索详情顶栏白底白字修复

**现象**：线索详情顶部通栏「像消失」——实际存在但白底白字看不见。

**根因**：`_buildNavBar()` 显式 `backgroundColor: Colors.white` + `surfaceTintColor: Colors.white`，但**未覆盖 `foregroundColor`**；全局 `appBarTheme`（`component_tokens.dart:142`）= 蓝底 `#0052D9` + **白字白图标**，前景沿优先级落到主题白色 → 白底白字不可见。

**修法**：移除两行 white 覆盖，`AppBar` 回退全局 `appBarTheme`（蓝底白字 + 居中），与全站其他通栏一致。改动仅 `lead_detail_page.dart` 2 行（删覆盖 + 注释）。

## 三、关键约定与踩坑（今日新增，详见 DEVELOPMENT_PITFALLS）

- **§11.12 首页接口合并**：合并前先全局 grep 被删字段/方法的全部引用，分清「首页私有」与「共享 provider」；复用既有模型时 import 是第一道关。
- **§11.13 通话记录缓存/拨打人**：缓存必须放**服务层单例**（页面销毁即丢，做不到退出再进命中）；`peekCache` 命中判断放重入锁**之前**；角色判定对齐后端**真实枚举值**；拨打人复用既有 options 缓存；下拉刷新 `force=true` 绕过缓存。
- **§11.14 AppBar 白底白字**：改 AppBar 背景/前景必须**成对改**，或干脆不覆盖、复用全局 `appBarTheme`；动背景前先想清楚前景色从哪来——本项目通栏统一蓝底白字，任何页面「自己来」都得把两色设齐。

**通用 UI 约定**（开发必读 `docs/dev/UI_STYLE_GUIDE.md`）：
- 颜色统一 `BrandColors.*`：`primary`(#0052D9 蓝) / `surface`(#F3F3F3 灰底) / `textPrimary`(#181818) / `textSecondary`(#A6A6A6)
- 公共组件：`AppSearchBar` / `AppFormSection` / `AppActionBar` / `AppDialog` / `AppBottomSheet` / `AppTextarea` / `AppToast`
- 通栏（AppBar）全站统一蓝底白字，页面不要单独白底
- 角色：`tenant_manager` / `tenant_admin`（TM/TA 是简称）；`TE` = 普通电销
- 调试：Alice 浮窗（`flutter build apk --release --dart-define=DEV_TOOLS=true`），点浮标看全部请求
