## 三、今日关键技术决策

### 3.1 release 联网根因 = main 清单缺 INTERNET 权限

**问题**：所有 release 包（含旧版）都"网络连接失败"，debug 包正常。

**根因**：Flutter 的 `src/debug/` 和 `src/profile/` AndroidManifest 自带 `INTERNET` 权限，但 `src/main/AndroidManifest.xml` 默认不带。release 构建只合并 main 清单 → 所有 release 包无联网权限 → Dio 请求被系统拒绝。

**修复**：`android/app/src/main/AndroidManifest.xml` 补 `<uses-permission android:name="android.permission.INTERNET" />`。

**教训**：Flutter 项目 release 联网必须显式声明 INTERNET 权限，不能依赖 debug 清单。此前多轮排查（Alice 顶层 final 污染网络栈 / release 吞异常 / 隧道 DNS）均属误判。

### 3.2 Alice 网络浮窗（dev-only）

- 开关：`bool.fromEnvironment('DEV_TOOLS', defaultValue:false)`，构建时 `--dart-define=DEV_TOOLS=true` 才注入。
- alice 1.0.0 已无 `getDioInterceptor()` 和自动浮标，需用 `AliceDioAdapter` + 自建浮标按钮。
- Alice 实例必须**懒加载**（`AliceManager.instance`），不能模块顶层 `final` 初始化——AOT release 下早于 Flutter 引擎就绪会污染网络栈。
- Android 构建必须开 core library desugaring（alice 间接依赖 flutter_local_notifications）。
- 浮标可拖拽（`GestureDetector.onPanUpdate` + `Positioned`）。

### 3.3 日程列表分组规则重构

从"按天分桶"改为"语义桶"模型：已逾期 / 今天 / 明天 / 后天 / 本周 / 下周 / 更晚（待办 Tab），已完成 Tab 镜像：今天 / 昨天 / 本周 / 上周 / 更早。每类别仅一个头，同类日程归同一桶，标签不重复。

### 3.4 日程搜索页用独立页面（非改造现有列表页）

日程列表页用全局共享 `scheduleListProvider`（底部 Tab 也用它），从线索详情跳过去改全局 q 会污染底部 Tab 状态 → 新建 `ScheduleSearchPage`（局部 state），通话记录页本来就是局部 state → 直接加 `initialQuery` 参数。

### 3.5 代码审查固化三条硬规则

写入 `docs/dev/STYLE_GUIDE.md` v1.1：
1. **§2.3 单文件 560 行红线**：硬性上限，超限必须拆分。
2. **§8.2 阻塞级修复独占提交**：release 装不上/起不来/核心流程断的修复不得与功能/样式/文档混提交。
3. **§8.2 commit message 措辞如实**：禁绝对词（全部/统一/重构）除非真全覆盖 100%。

### 3.6 拆分手法：`part of` + `extension on State`

跨文件拆分首选方案，访问私有状态零样板。前提：part of 在 part 文件顶部、主文件 part 指令在 import 后、ext 内 setState 加 `// ignore_for_file: invalid_use_of_protected_member`。
