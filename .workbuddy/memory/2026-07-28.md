## 线索列表「待跟进优先」改用 pendingPriority 专用排序（已开发+真机验证）
- 问题：此前用 `sort=nextFollowupAt`（按 nextFollowupAt 升序），但无跟进计划的线索该字段为 null，排序语义混乱、数据不合理。
- 后端沟通后新增专用参数 `sort=pendingPriority`：assigned 状态置顶 → 其余按 nextFollowupAt 升序 → 无计划（NULL）排最后（NULLS LAST）。
- 改动：`lead_list_provider.dart`（`sortBy` 默认 `'nextFollowupAt'`→`'pendingPriority'`、`toggleSort()` 切换值同步改）；`leads_filter_sheet.dart`（「待跟进优先」选项 value `'nextFollowupAt'`→`'pendingPriority'`）；`docs/api.md` 补 `sort`/`sort=pendingPriority` 说明。
- 未动：公海列表（`scope=public`）仍用 `sort='-updatedAt'`，与「待跟进优先」无关。
- 与顶栏计数功能（用户开发）一并随 v0.36 提交推送。
