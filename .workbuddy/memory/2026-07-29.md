## 紧急回归修复：管理员首页灰屏（本批次 P0-1 引入）
- 现象：用户以管理员登录首页"骨架屏→灰屏"、员工正常。
- 根因：上轮 UI 修复 P0-1 给 `home_stats_section._buildTeamGrid` 的 Row **裸加** `CrossAxisAlignment.stretch`；外层 `AppCardSection→Column` 垂直无界约束（h=Infinity）下，stretch 把无限高度传给子卡内部 Column → `BoxConstraints forces an infinite height` 崩溃。员工分支 Row 无 stretch 故正常。
- 定位：本地 widget_test 用管理员 mock 数据 `pumpWidget(HomeStatsSection)` 稳定复现并拿到堆栈（确认在布局层非数据层）。
- 修复：每个 Row 用 **`IntrinsicHeight`** 包裹（保留 stretch），重跑 test `All tests passed`、analyze `No issues`、删临时 test。
- 教训（通用 Flutter 陷阱）：垂直无界约束容器内对 Row 用 `stretch` 等高，**必须** `IntrinsicHeight` 包裹，否则传播无限高度整页崩。
