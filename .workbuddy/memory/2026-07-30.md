## 两个关键坑（已解决，详见 MEMORY.md 的「miniapp / Taro 子项目」小节）
1. pnpm 原生包构建脚本默认被忽略（esbuild / @tarojs/binding / @swc/core 等），需用 `miniapp/pnpm-workspace.yaml` 的 `allowBuilds` 白名单放行，否则 taro build 可能找不到 native binding。
2. `*.config.ts`（app.config.ts / page.config.ts）**不要** `import { defineAppConfig } from '@tarojs/taro'`——构建加载配置阶段会在 Node 里 require 到 @tarojs/runtime，因 ENABLE_INNER_HTML 等编译期全局常量（仅由 webpack DefinePlugin 注入）未定义而崩溃。改为直接 `export default { ... }` 纯对象即可。
